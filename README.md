# Веб-сервер: Планировщик задач (go-pher-tasks)

Реализация веб-сервиса для создания, редактирования и поиска задач с использованием HTTP API.

## 📝 Описание проекта

Проект представляет собой бэкенд-сервис на Go, который предоставляет API для управления задачами. Основной функционал включает:

*   Создание, редактирование, удаление и получение задач.
*   Хранение данных в локальной файловой базе данных SQLite (`scheduler.db`).
*   Поддержку авторизации по токену.
*   Расширенный функционал для поиска задач по строке и дате.

Сервер предназначен для использования в качестве бэкенда для веб- или мобильного приложения-планировщика.

## ⭐ Список выполненных заданий со звёздочкой

В данном проекте были реализованы следующие задания повышенной трудности:

*   **Поиск задач:** Добавлен обработчик `GET /api/tasks?search=...`, который позволяет искать задачи по вхождению строки в название или комментарий.
*   **Получение следующей задачи:** Реализован обработчик `GET /api/tasks/next`, который возвращает ближайшую по дате невыполненную задачу.

## 🚀 Инструкция по запуску кода локально

### Требования
*   Go (версия 1.18+ или аналогичная)

### Запуск

1.  **Клонируйте репозиторий:**
    ```sh
    git clone <ссылка_на_ваш_репозиторий>
    cd go-pher-tasks
    ```

2.  **Настройте переменные окружения:**
    Перед запуском необходимо установить две переменные окружения:
    *   `TODO_PORT` — порт, на котором будет работать веб-сервер (например, `7540`).
    *   `TODO_PASSWORD` — пароль, который будет использоваться для генерации токена авторизации.

3.  **Запустите сервер:**
    Установите переменные и запустите приложение командой `go run main.go`.

    **Для Linux / macOS:**
    ```sh
    # Установка переменных и запуск одной командой
    TODO_PORT=7540 TODO_PASSWORD="your-super-secret-password" go run main.go
    ```
    *Или так:*
    ```sh
    # Установка переменных по отдельности
    export TODO_PORT=7540
    export TODO_PASSWORD="your-super-secret-password"
    go run main.go
    ```

    **Для Windows (Command Prompt):**
    ```cmd
    set TODO_PORT=7540
    set TODO_PASSWORD="your-super-secret-password"
    go run main.go
    ```

    **Для Windows (PowerShell):**
    ```powershell
    $env:TODO_PORT="7540"
    $env:TODO_PASSWORD="your-super-secret-password"
    go run main.go
    ```

4.  **Адрес в браузере:**
    После запуска сервер будет доступен по адресу: `http://localhost:<порт>`, где `<порт>` — это значение, которое вы указали в переменной окружения `TODO_PORT` (например, **http://localhost:7540**).

## 🧪 Инструкция по запуску тестов

### Настройка
Перед запуском тестов убедитесь, что файл `tests/settings.go` сконфигурирован правильно. Параметры в нем должны соответствовать настройкам запущенного сервера.

Пример корректной конфигурации файла `tests/settings.go`:
```go
package tests

// Port - порт, на котором запущен ваш сервер для тестов.
// Должен совпадать с портом из флага -p при запуске сервера.
var Port = 7540

// DBFile - путь к файлу базы данных относительно папки с тестами.
var DBFile = "../scheduler.db"

// FullNextDate - флаг, включающий тесты для /api/tasks/next.
var FullNextDate = true

// Search - флаг, включающий тесты для поиска задач.
var Search = true

// Token - ваш токен авторизации для доступа к API.
// Вставьте сюда действительный токен (в браузере откройте Инструменты разработчика (F12) -> Application -> Cookies.
// Найдите куку с именем token и скопируйте её значение)
var Token = "ВАШ_СЕКРЕТНЫЙ_ТОКЕН"
```
### Выполнение тестов
Для запуска тестов выполните следующую команду из корневой директории проекта:

```sh
go test ./tests/...
```
### 🐳Инструкция по запуску через Docker
Сборка Docker-образа:

```sh
docker build -t go-pher-tasks .
```
Запуск контейнера:
Эта команда запустит контейнер и пробросит порт 7540 с хост-машины в контейнер. Файл базы данных scheduler.db будет создан на хост-машине и подключен к контейнеру, чтобы данные не терялись при перезапуске.

```sh
docker run --rm -d \                                                                 
  -p 7540:7540 \
  -e TODO_PORT="7540" \
  -e TODO_PASSWORD="my_secret_docker_password" \
  -e TODO_DBFILE="/app/scheduler.db" \
  -v $(pwd)/scheduler.db:/app/scheduler.db \
  --name my-scheduler \
  go-task-scheduler
```
Сервер будет доступен по адресу http://localhost:7540.
